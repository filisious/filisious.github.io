# Проверка проекта

Проверено 30 сентября 2026 года в headless Chromium. Проверки выполнены на настоящем DOM с Playwright; системные окна Web Share и Clipboard заменялись контролируемыми mock-реализациями для проверки ветвей обработки.

## Успешные проверки

- 36 сочетаний: ширины 320, 375, 390, 430, 768 и 1440 px × светлая/тёмная тема × EN/RU/FA. Горизонтального переполнения нет.
- Визуально просмотрены финальные снимки EN light, FA dark и QR fullscreen.
- Персидский интерфейс использует dir=rtl; телефон, email, ссылки и AK остаются LTR.
- RU/FA определяются по языку браузера. Ручной выбор сохраняется после перезагрузки. При запрещённом localStorage переключение работает.
- WhatsApp без текста сообщения, Telegram, tel и mailto без subject/body соответствуют данным.
- Сформированный VCF содержит vCard 3.0, правильные N/FN, CRLF и строки не длиннее 75 UTF-8 байт.
- Web Share получает правильный URL; при отсутствии API копируется ссылка; при запрете автоматического копирования доступно ручное поле.
- Генерация QR проверена из матрицы и из снимка реально отрисованного QR независимым декодером ZXing. Расшифрованный URL совпал с ожидаемым.
- QR: чёрный/белый, 4 модуля свободного поля, коррекция M, без логотипа; в 320×568 помещается полностью.
- Escape, возврат фокуса на кнопку, циклическое перемещение Tab/Shift+Tab в модальном окне, блокировка фоновой прокрутки.
- Graceful fallback при ошибке генерации QR.
- prefers-reduced-motion отключает анимацию.
- Увеличение базового размера шрифта до 200% в FA на 320 px не создаёт горизонтального скролла.
- Загрузка страницы offline после установки service worker.
- Реальная загрузка из /business-card/ и отдельная проверка URL в корне / с маршрутизацией локальных файлов. Относительные CSS/JS/иконки и QR работают в обеих схемах.
- JavaScript проходит node --check. В основной браузерной проверке необработанных ошибок JavaScript нет.

## Ограничения проверки

Это не тест на физических iPhone/Android и не полная сертификация accessibility. Импорт в Apple Contacts/Google Contacts, системный Web Share, установка PWA и считывание QR камерой при разной яркости требуют финальной проверки после публикации. Публичный GitHub Pages URL ещё не создан: учётные данные и имя репозитория пользователя не запрашивались и не выдумывались. Временные example/card.test URL использовались только тестами и не включены в config.js.

Первое открытие требует сети. Offline-кэш может удаляться браузером. Работа мессенджеров зависит от устройства и доступности самих сервисов. Метаданные Open Graph содержат title/description/type; og:url и og:image намеренно не ссылаются на несуществующий домен. Если впоследствии добавите превью-изображение, укажите его публичный абсолютный URL вручную.
